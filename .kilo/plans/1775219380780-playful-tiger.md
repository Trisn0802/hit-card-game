# Plan: Desain Tombol & Kartu Joker untuk Table Power Up

## Latar Belakang
Memperbaiki tampilan tombol Joker yang ada menjadi kartu visual yang menarik seperti kartu di table, dengan desain kartun yang muncul di area table cards player. Desain harus responsif untuk desktop dan mobile.

## Files yang Diubah
- `style.css` - CSS untuk kartu joker dan responsive
- `script.js` - Logic untuk render kartu joker di table area

## Perubahan Spesifik

### 1. Desain Kartu Joker (CSS)
- **Desktop**: Ukuran 80px x 110px (sama seperti kartu biasa)
- **Mobile**: Ukuran 50px x 70px (sesuai responsive card)
- **Desain kartun**:
  - Background gradient: ungu ke pink (#9b59b6 → #e91e63)
  - Ada icon/joker face (menggunakan emoji atau CSS art)
  - Text besar "JOKER" di tengah
  - Border gold (#f1c40f)
  - Efek kilau/gradient overlay
  - Animasi pulse halus saat aktif

### 2. Posisi di Table Area (HTML/JS)
- Kartu joker muncul di area `table-cards` player (id: `playerTable`)
- Muncul saat `gameState.playerHasJoker === true` dan `jokerUsed === false`
- Posisi di awal array table cards (index 0)
- Jika ada kartu lain di table, joker bisa di tengah atau di samping

### 3. Tombol Joker yang Ada
- Tombol tetap ada di controls tetapi lebih kecil/sekunder
- Klik tombol -> memunculkan modal aksi (reshuffle/swap)
- Tombol menunjukkan indikator visual bahwa joker tersedia

### 4. CSS Responsive

### 5. Implementasi JS
- Fungsi `renderJokerCard()` - render kartu joker ke player table
- Panggil di `updateJokerUI()` dan `startNewGame()`
- Hapus kartu joker saat joker digunakan (`jokerUsed = true`)

### 6. Visual Elements Kartu Joker

- Gradient background ungu-pink

## Hasil yang Diharapkan
- Kartu joker muncul di area table player saat mendapat joker
- Desain menarik dan responsif untuk semua ukuran layar
- Tombol joker di controls tetap berfungsi untuk memilih aksi

### 2. script.js - Perubahan Utama

#### A. `startNewGame()` - Ubah kartu yang dibagikan dari 5 ke 6
```javascript
// Sebelum
gameState.playerHand = drawCards(deck, 5);
gameState.botHand = drawCards(deck, 5);

gameState.playerHand = drawCards(deck, 6);

checkForJokerInHand(gameState.playerHand, 'player');
checkForJokerInHand(gameState.botHand, 'bot');
```

#### B. Fungsi baru `checkForJokerInHand(hand, actor)`
```javascript
function checkForJokerInHand(hand, actor) {
    // Cek apakah ada special property 'joker' di kartu
    const hasJoker = hand.some(card => card.isJoker);
    if (hasJoker) {
        if (actor === 'player') {
            gameState.playerHasJoker = true;
        } else {
            gameState.botHasJoker = true;
        }
    }
}
```

#### C. Fungsi baru untuk buat kartu joker

```javascript
function createJokerCard() {
```

```javascript
const newCards = drawCards(deck, numCardsToReplace);

// Cek apakah ada joker di antara kartu baru (misal 10% chance per kartu)
newCards.forEach(card => {
    if (Math.random() < 0.10) {
        card.isJoker = true;
        card.value = 'JOKER';
        card.suit = 'joker';
    }
});

hand.push(...newCards);

// Update status joker
if (hand.some(c => c.isJoker)) {
    if (actor === 'player') {
        gameState.playerHasJoker = true;
    } else {
        gameState.botHasJoker = true;
    }
}
```

1. **Awalan game**: Pemain dan bot dibagikan 6 kartu (5 regular + kemungkinan 1 joker)
